# Цель работы
 
 Целью данной лабораторной работы является приобретение практических навыков по первичной настройке сетевого оборудования Cisco, изучение базовых команд операционной системы Cisco IOS, а также освоение принципов организации удалённого доступа к маршрутизатору и коммутатору.
 
  рамках выполнения работы необходимо было:
    • собрать простую сетевую топологию в Cisco Packet Tracer;
    • выполнить начальную конфигурацию маршрутизатора и коммутатора;
    • назначить IP-адреса интерфейсам устройств;
    • настроить VLAN на коммутаторе;
    • организовать защищённый удалённый доступ по SSH;
    • проверить корректность работы сети с помощью диагностических команд.
    
# Ход выполнения лабораторной работы
 
1. Построение топологии сети
  
  В логической рабочей области Cisco Packet Tracer была создана сеть, включающая следующие устройства:
    • маршрутизатор Cisco 2811 (msk-donskaya-babdulvahid-gw-1);
    • коммутатор Cisco 2960-24TT (msk-donskaya-babdulvahid-sw-1);
    • два персональных компьютера: PC0-babdulvahid и PC1-babdulvahid.
Соединение устройств выполнено следующим образом:
    • PC0 подключён напрямую к маршрутизатору;
    • PC1 подключён к коммутатору;
    • для подключения использовались прямые витопарные кабели (Copper Straight-Through), так как соединялись устройства разных типов.
Таким образом была реализована простейшая модель локальной сети, состоящей из двух подсетей.

 ![Топология сети](1.jpg){ #fig:001 width=80% }
 
2. Настройка ПК0
  
  На персональном компьютере PC0 был вручную задан статический IP-адрес для взаимодействия с маршрутизатором.
Параметры настройки:
    • IP-адрес: 192.168.1.10
    • Маска подсети: 255.255.255.0
    • Шлюз по умолчанию: 192.168.1.254
Назначение статического IP-адреса позволило обеспечить корректную адресацию внутри первой подсети и последующую проверку связи с маршрутизатором.

![Настройка ПК0](2.jpg){ #fig:001 width=80% }

3. Настройка маршрутизатора Cisco 2811

Первичная настройка маршрутизатора выполнялась через консольное подключение.
  На интерфейсе FastEthernet0/0 были выполнены следующие действия:
    • назначен IP-адрес 192.168.1.254;
    • установлена маска подсети 255.255.255.0;
    • интерфейс переведён в активное состояние командой no shutdown.
Далее была выполнена базовая конфигурация безопасности устройства:
    • задано имя устройства (hostname);
    • установлен пароль привилегированного режима (enable secret);
    • включено шифрование паролей (service password-encryption);
    • настроены линии VTY для удалённого доступа;
    • создан локальный пользователь admin с паролем;
    • задано доменное имя;
    • сгенерированы RSA-ключи;
    • активирован протокол SSH версии 2;
    • конфигурация сохранена в энергонезависимую память.
Настройка SSH обеспечивает защищённый удалённый доступ к устройству, что является важным требованием информационной безопасности.

4. Проверка соединения с маршрутизатором

С компьютера PC0 была выполнена команда ping до IP-адреса маршрутизатора 192.168.1.254.
Все отправленные пакеты были успешно доставлены, что свидетельствует о корректной настройке интерфейса маршрутизатора и правильной адресации ПК.
Также были протестированы способы удалённого подключения:
    • Telnet — соединение устанавливалось, но не обеспечивало защищённый канал;
    • SSH — выполнен успешный вход под пользователем admin и корректный выход из сеанса.
Таким образом, маршрутизатор был настроен правильно и готов к эксплуатации.

5. Настройка коммутатора Cisco 2960

Для организации удалённого управления коммутатором был создан интерфейс VLAN 2.
Параметры:
    • IP-адрес: 192.168.2.1
    • Маска: 255.255.255.0
Интерфейс VLAN был активирован, а порт, к которому подключён PC1, переведён в режим access и назначен в VLAN 2.
Дополнительно выполнена настройка:
    • задано имя устройства;
    • установлены пароли для консоли и линий VTY;
    • настроен enable secret;
    • включено шифрование паролей;
    • создан пользователь admin;
    • задано доменное имя;
    • сгенерированы RSA-ключи;
    • включён доступ по SSH;
    • настроен шлюз управления.
Это позволило обеспечить централизованное и безопасное администрирование коммутатора.

# Контрольные вопросы

1. Возможные способы подключения к сетевому оборудованию
Подключение возможно следующими способами:
    • через консольный порт (локальное подключение);
    • через Telnet;
    • через SSH;
    • через веб-интерфейс (если поддерживается).
    
2. Подключение ПК к маршрутизатору
Используется прямой витопарный кабель (Copper Straight-Through), так как соединяются устройства разных типов: конечное устройство и сетевое оборудование.

3. Подключение ПК к коммутатору
Также используется прямой кабель, поскольку соединяются разные типы устройств.

4. Подключение коммутатора к коммутатору
Применяется перекрёстный кабель (Copper Cross-Over), так как соединяются однотипные устройства.

5. Способы настройки доступа по паролю
Настройка возможна:
    • для консоли (line console 0);
    • для линий VTY;
    • через enable secret;
    • через создание локальных пользователей.
    
6. Способы удалённого доступа
Удалённый доступ реализуется через Telnet и SSH.
Предпочтительным является SSH, так как он обеспечивает шифрование передаваемых данных и защиту от перехвата информации. Telnet передаёт данные в открытом виде, что делает его менее безопасным.
