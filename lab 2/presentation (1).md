# Цели и задачи работы

## Цель лабораторной работы
Целью данной лабораторной работы является приобретение практических навыков по первичной настройке сетевого оборудования Cisco, изучение базовых команд операционной системы Cisco IOS, а также освоение принципов организации удалённого доступа к маршрутизатору и коммутатору.

## Задачи лабораторной работы
- Назначение IP-адресов
- Конфигурация интерфейсов
- Создание VLAN
- Настройка паролей доступа
- Организация удалённого управления по SSH
- Проверка соединений с использованием команды ping

# Выводы лабораторной работы

## Вывод
В ходе лабораторной работы Абдуллахи Абдул Вахид выполнил сборку и настройку простой сети в Cisco Packet Tracer, состоящей из маршрутизатора, коммутатора и двух персональных компьютеров. Были успешно освоены базовые навыки:  
- назначение IP-адресов  
- конфигурация интерфейсов  
- создание VLAN  
- настройка паролей доступа  
- организация удалённого управления по SSH  

Проверка соединений с использованием команды ping показала корректную работу сети. Настроенные механизмы удалённого доступа функционируют стабильно, что подтверждает правильность выполненной конфигурации.
